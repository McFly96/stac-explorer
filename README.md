# stac-viewer
Search, view and compare Sentinel-2 imagery in the browser from a public STAC catalogue. COGs are read over HTTP and rendered on the GPU with OpenLayers: true/false colour, NDVI, NDWI, before/after swipe, shareable links. No tile server. React + TypeScript, tests and CI. Includes the UX design: a 4-page sketch-style mock-up.
